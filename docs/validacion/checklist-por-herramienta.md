# Lista de comprobación antes de cada sesión de evaluación

- [ ] Versión de la herramienta anotada y coincide con la versión congelada del estudio.
- [ ] El caso está seudonimizado y verificado por una segunda persona; el texto no contiene datos identificativos.
- [ ] Los evaluadores A y B han terminado y registrado su estratificación **antes** de abrir la herramienta.
- [ ] El evaluador C no conoce las puntuaciones de A y B.
- [ ] Se anota la condición de uso: (a) entrada manual o (b) texto pegado y revisado.
- [ ] Se registran las variables que quedaron pendientes y por qué.
- [ ] Si hay modificación profesional, se anota el nivel y el motivo codificado (sin texto libre).
- [ ] Se descarga el informe JSON y se archiva con el código de estudio.
- [ ] Cualquier comportamiento inesperado se anota con el caso mínimo que lo reproduce.
